# 我的书房 (my-library)

[한국어](README.md) · [English](README.en.md) · **中文** · [日本語](README.ja.md)

一个按章节阅读自己藏书的网页应用。放入书的 PDF（扫描版也可以）或书页照片，就会**在你自己的设备上**识别文字、按章划分并放上书架。无需安装即可在浏览器中使用，也可以像应用一样安装。

**打开：** https://kimppi-1.github.io/my-library/

## 功能

- **添加书籍**：多个 PDF（上下册）或多张照片可以合成一本书。
  - 带文字的 PDF 直接提取文字；扫描版 PDF 用文字识别（tesseract.js）读取。
  - 经文章节（`3:16`）等小数字以及韩文中的英文单词，会放大后重新识别。
  - **找回漏读的行**：整页识别漏掉的灰色副标题、大标题等，会提高对比度后逐行重读。
  - **圣经章节纠正**（韩文书籍）：用 66 卷 1,189 章的节数表只保留真实存在的章节，并依据从整本书学到的数字误读倾向纠正（`롬 512` → `롬 5:12`）。
  - **再用 AI 校对一遍（可选）**：用你的 Claude、ChatGPT 或 Gemini 密钥，AI 直接查看页面图片改正错字。与识别结果差别过大的回答不会采用，避免编造内容。每页会产生 AI 费用。
  - 韩文书籍：用 Kiwi 韩语语言模型纠正识别错误的字，沿用 [hwp2docx](https://github.com/kimppi-1/hwp2docx) 的方法。
  - **保护重要词语**（韩文书籍）：하나님(上帝)、예수(耶稣)、그리스도(基督)、성령(圣灵)、성경(圣经)、圣经 66 卷书名以及主要神学词语，识别出错时会被更正。可以在设置中添加自己的词语。
- **书的语言**：韩文、英文、中文（简体 · 繁体）、日文。
- **划分章节**：带大字标题的页面会被推测为章节开始。每一页都可以选择“正文 / 新章节开始 / 部分扉页 / 排除”，并修改标题。
- **阅读**：目录、已读标记、可夹在任何段落的书签、字体 · 字号 · 行距 · 背景色 · 文字颜色 · 边距设置、翻书效果、阅读进度条、用 ← → 键切换章节。
- **荧光笔和笔记**：拖选文字即可用四种颜色标记并添加笔记。可以集中查看、按颜色筛选、搜索、一次全部复制。
- **思考题和测验**：AI 为每章生成摘要、3 道思考题和 4 道选择题，语言与所选的界面语言一致。也可以一次为所有章节生成。
  - **复制粘贴（无需密钥）**：把提示词复制到你常用的 AI 应用（Claude、ChatGPT、Gemini …），再把回答粘贴回来。
  - **API 密钥**：输入你自己的 Claude（Anthropic）、ChatGPT（OpenAI）或 Gemini（Google）密钥，应用会直接生成。密钥只保存在那台设备上。
- **备份**：把书籍和记录导出为一个文件，在其他设备上导入。
- **界面语言**：한국어 · English · 中文 · 日本語（右上角）。

## 隐私与版权

- 书籍文件、正文、阅读记录和笔记**只保存在你的浏览器（IndexedDB）中**，不会上传到本仓库或任何服务器。
- 只有在用 AI API 出题时（发送该章正文）或开启 AI 校对时（发送页面图片），才会向你选择的 AI 公司发送内容。此外不发送任何内容。
- 本仓库不包含任何书籍。请放入**你自己拥有的书，用于个人学习**，不要与他人分享生成的正文。

## 安装

- **电脑（Chrome · Edge）**：地址栏右侧的安装按钮（或 设置 → 安装到这台设备）。会出现在桌面和开始菜单中，并在独立窗口中打开。
- **iPhone**：Safari 分享按钮 → 添加到主屏幕。
- **Android**：Chrome 菜单 → 安装应用。

打开一次后即可离线使用。文字识别数据（首次约 15 MB）和韩语纠错模型（约 28 MB）在第一次添加书籍时下载一次。

## 部署到自己的仓库（Fork）

1. Fork 本仓库，或把文件上传到新仓库。
2. Settings → Pages → 将 Branch 设为 `main` / `(root)` 并保存。
3. 稍等片刻即可在 `https://<账号>.github.io/<仓库>/` 打开。

没有构建步骤：修改 HTML 和 JavaScript 文件后会直接生效。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 页面框架和样式 |
| `src/app.mjs` | 书房、目录、阅读、荧光笔、设置页面 |
| `src/importer.mjs` | 添加书籍和划分章节页面 |
| `src/ocr.mjs` | PDF 文字提取、文字识别、重新识别章节和英文、纠错 |
| `src/chapters.mjs` | 根据行的大小和位置找出章节标题、副标题、经文引言和段落 |
| `src/glossary.mjs` | 保护重要词语 |
| `src/refs.mjs`、`src/bible-meta.mjs` | 圣经章节纠正与章节数表 |
| `src/ai.mjs` | 选择 AI 与提示词 |
| `src/i18n.mjs`, `src/i18n-dict.mjs` | 界面语言与翻译词典 |
| `src/store.mjs` | 设备内存储（IndexedDB） |
| `src/ko-fix.mjs` | 来自 hwp2docx 的韩文错字纠正 |
| `vendor/` | pdf.js、Kiwi 语言模型 |
| `sw.js`, `manifest.webmanifest` | 安装与离线使用 |
