# 내 서재 (my-library)

**한국어** · [English](README.en.md) · [中文](README.zh.md) · [日本語](README.ja.md)

가지고 있는 책의 PDF(스캔한 것도 됩니다)나 책장 사진을 넣으면, **이 기기 안에서** 글자를 읽어 장별로 나누고
한 장씩 읽으며 익힐 수 있게 해 주는 웹 앱입니다. 설치 없이 브라우저로 쓰거나, 앱처럼 설치해 쓸 수 있습니다.

**바로 쓰기:** https://kimppi-1.github.io/my-library/

## 할 수 있는 것

- **책 추가**: PDF 여러 개(앞권·뒷권)나 사진 여러 장을 한 권으로 묶어 넣습니다.
  - 글자가 든 PDF는 글자를 그대로 꺼내고, 스캔한 PDF는 한국어 글자 인식(tesseract.js)으로 읽습니다.
  - 성경 장절처럼 작은 숫자(`3:16`)와 영어 낱말은 그 자리만 크게 키워 다시 읽습니다.
  - 틀린 글자는 한국어 언어 모형(Kiwi)으로 바로잡습니다 — [hwp2docx](https://github.com/kimppi-1/hwp2docx)의 방식입니다.
  - **빠진 줄 되살리기**: 회색 부제목·큰 제목처럼 한 쪽 전체 읽기가 놓치는 줄은 대비를 높여 한 줄씩 다시 읽습니다.
  - **성경 장절 바로잡기**: 성경 66권 1,189장의 절 수 표(31,103절)로 '실제로 있을 수 있는 장절'만 남깁니다. 책 한 권에서 배운 숫자 오독 경향(5↔3, 1↔3 …)과 빠진 쌍점을 따져 `롬 512` → `롬 5:12`, `웹 4:10` → `엡 4:10`처럼 고칩니다.
  - **AI로 한 번 더 바로잡기(선택)**: 설정에 넣은 Claude·ChatGPT·Gemini 키로, AI가 쪽 사진을 직접 보고 오타를 고칩니다. 원래 읽은 줄과 너무 다른 답은 쓰지 않아 지어낸 글이 들어가지 않게 합니다. 쪽마다 AI 요금이 듭니다.
  - **중요한 낱말 지키기**: 하나님·예수·그리스도·성령·성경, 성경 66권 이름, 주요 신학 낱말이 틀리게 읽히면 바로잡습니다. 설정에서 낱말을 더할 수 있습니다.
- **장 나누기**: 큰 글씨 제목이 있는 쪽을 장 시작으로 짐작해 보여 주고, 쪽마다 '본문 / 새 장 / 부 표지 / 빼기'를 고르고 제목을 고칠 수 있습니다.
- **읽기**: 장 목록, 읽음 표시, 책갈피(문단마다), 글꼴·크기·줄 간격·배경색·글씨색·여백 설정, 책장 넘김 효과, 읽는 자리 표시줄, ←→ 키로 장 넘기기.
- **형광펜·메모**: 글을 끌어 고르면 네 가지 색으로 칠하고 메모를 답니다. 모아 보기에서 찾고, 색별로 거르고, 한꺼번에 복사합니다.
- **질문·문제**: 장마다 요약, 생각할 질문 3개, 객관식 확인 문제 4개를 AI로 만듭니다. 모든 장을 한꺼번에 만들 수도 있습니다.
  - **복사해서 쓰기(키 없이)**: 요청문을 복사해 평소 쓰는 AI 앱(Claude, ChatGPT, Gemini …)에 붙여 넣고 답을 다시 붙여 넣습니다.
  - **API 키**: Claude(Anthropic), ChatGPT(OpenAI), Gemini(Google) 중 자기 키를 넣으면 앱이 바로 만듭니다. 키는 그 기기에만 저장됩니다.
- **백업**: 책과 기록을 파일 하나로 내보내 다른 기기에서 불러옵니다.
- **여러 언어**: 화면은 한국어·English·中文·日本語 가운데 골라 쓰고(오른쪽 위), 책은 한국어·영어·중국어(간체·번체)·일본어 책을 읽을 수 있습니다. AI 질문·문제도 고른 화면 언어로 만듭니다.

## 개인 정보와 저작권

- 책 파일, 본문, 읽은 기록, 메모는 모두 **쓰는 사람의 브라우저(IndexedDB)에만** 저장됩니다. 이 저장소나 어떤 서버에도 올라가지 않습니다.
- AI로 질문을 만들 때는 그 장의 본문이, 'AI로 한 번 더 바로잡기'를 켰을 때는 쪽 사진이, 쓰는 사람이 고른 AI 회사로 보내집니다. 그 밖에는 아무것도 보내지 않습니다.
- 이 저장소에는 책이 들어 있지 않습니다. **각자 가지고 있는 책을 개인 공부용으로** 넣어 쓰세요. 만든 본문을 다른 사람과 나누지 마세요.

## 설치해서 쓰기

- **컴퓨터(크롬·엣지)**: 주소창 오른쪽의 설치 단추(또는 앱의 설정 → '이 기기에 설치'). 바탕화면·시작 메뉴에 생기고 따로 창으로 열립니다.
- **아이폰**: 사파리 공유 단추 → '홈 화면에 추가'.
- **안드로이드**: 크롬 메뉴 → '앱 설치'.

한 번 열면 인터넷 없이도 읽을 수 있습니다. 글자 인식 자료(처음 한 번 약 15MB)와 맞춤법 모형(약 28MB)은 처음 책을 넣을 때 받아 저장해 둡니다.

## 내 저장소에 올려 쓰기 (포크)

1. 이 저장소를 포크하거나 파일을 그대로 새 저장소에 올립니다.
2. 저장소 Settings → Pages → Branch를 `main` / `(root)`로 두고 저장합니다.
3. 잠시 뒤 `https://<계정>.github.io/<저장소>/` 에서 열립니다.

빌드 과정이 없습니다. HTML과 자바스크립트 파일을 고치면 바로 반영됩니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 틀과 모양 |
| `src/app.mjs` | 서재·목차·읽기·형광펜·설정 화면 |
| `src/importer.mjs` | 책 추가와 장 나누기 화면 |
| `src/ocr.mjs` | PDF 글자 꺼내기, 글자 인식, 빠진 줄 되살리기, 장절·영어 다시 읽기, 맞춤법, AI 교정 |
| `src/chapters.mjs` | 쪽의 줄 크기·자리로 장 제목·부제·성경 인용·문단 찾기 |
| `src/glossary.mjs` | 중요한 낱말 지키기 |
| `src/refs.mjs`, `src/bible-meta.mjs` | 성경 장절 바로잡기와 66권 장·절 수 표 |
| `src/ai.mjs` | AI 고르기와 요청문 |
| `src/store.mjs` | 기기 안 저장소(IndexedDB) |
| `src/i18n.mjs`, `src/i18n-dict.mjs` | 화면 언어 바꾸기와 번역 사전 |
| `src/ko-fix.mjs` | hwp2docx의 한글 오타 바로잡기 |
| `vendor/` | pdf.js, Kiwi 언어 모형 |
| `sw.js`, `manifest.webmanifest` | 설치·인터넷 없이 열기 |
