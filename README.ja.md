# マイ書斎 (my-library)

[한국어](README.md) · [English](README.en.md) · [中文](README.zh.md) · **日本語**

持っている本を章ごとに読むためのウェブアプリです。本の PDF（スキャンしたものも可）やページの写真を入れると、**自分の端末の中で**文字を読み、章ごとに分けて本棚に並べます。インストールせずにブラウザで使うことも、アプリのようにインストールすることもできます。

**開く：** https://kimppi-1.github.io/my-library/

## できること

- **本を追加**：複数の PDF（上巻・下巻）や写真をまとめて一冊にします。
  - 文字の入った PDF はそのまま文字を取り出し、スキャンした PDF は文字認識（tesseract.js）で読みます。
  - 聖書の章節（`3:16`）のような小さな数字や、韓国語の中の英単語は、その部分だけ拡大して読み直します。
  - **読み落とした行の復元**：ページ全体の認識が見落とす灰色のサブタイトルや大きな見出しを、コントラストを上げて一行ずつ読み直します。
  - **聖書の章節の修正**（韓国語の本）：66巻1,189章の節数表で実在する章節だけを残し、本一冊から学んだ数字の誤読傾向で直します（`롬 512` → `롬 5:12`）。
  - **AIでもう一度校正（任意）**：Claude・ChatGPT・Geminiのキーで、AIがページの画像を見て誤字を直します。認識結果と違いすぎる答えは使わず、作り話が入らないようにします。ページごとにAI料金がかかります。
  - 韓国語の本：誤読した文字を Kiwi 韓国語言語モデルで直します。[hwp2docx](https://github.com/kimppi-1/hwp2docx) の方法です。
  - **大事な言葉を守る**（韓国語の本）：하나님(神)・예수(イエス)・그리스도(キリスト)・성령(聖霊)・성경(聖書)、聖書66巻の書名、主な神学用語は、文字認識が間違えても直します。設定で言葉を加えられます。
- **本の言語**：韓国語・英語・中国語（簡体・繁体）・日本語。
- **章分け**：大きな文字のタイトルがあるページを章の始まりと推測します。ページごとに「本文 / 新しい章 / 部の扉 / 除く」を選び、タイトルを直せます。
- **読む**：目次、既読マーク、段落ごとのしおり、フォント・サイズ・行間・背景色・文字色・余白の設定、ページめくり効果、読書位置バー、← → キーで章を移動。
- **マーカー・メモ**：文字をなぞって選ぶと4色のマーカーを引き、メモを付けられます。一覧で探し、色で絞り込み、まとめてコピーできます。
- **問い・クイズ**：章ごとに要約、考える問い3つ、選択式の確認クイズ4つを AI で作ります。画面で選んだ言語で作られます。全章をまとめて作ることもできます。
  - **コピーして使う（キー不要）**：依頼文をコピーしていつもの AI アプリ（Claude、ChatGPT、Gemini …）に貼り付け、答えを貼り戻します。
  - **API キー**：Claude（Anthropic）、ChatGPT（OpenAI）、Gemini（Google）のどれかの自分のキーを入れると、アプリがすぐに作ります。キーはその端末にだけ保存されます。
- **バックアップ**：本と記録を一つのファイルに書き出し、別の端末で読み込みます。
- **画面の言語**：한국어 · English · 中文 · 日本語（右上）。

## プライバシーと著作権

- 本のファイル、本文、読書記録、メモは**使う人のブラウザ（IndexedDB）の中だけ**に保存されます。このリポジトリやどのサーバーにもアップロードされません。
- AI の API で問いを作るとき（その章の本文）と、AI校正をオンにしたとき（ページの画像）だけ、選んだ AI の会社へ送られます。それ以外は何も送りません。
- このリポジトリに本は含まれていません。**自分が持っている本を個人の学習用に**入れて使い、作った本文は他の人と共有しないでください。

## インストール

- **パソコン（Chrome・Edge）**：アドレスバー右のインストールボタン（または 設定 → この端末にインストール）。デスクトップとスタートメニューに入り、別ウィンドウで開きます。
- **iPhone**：Safari の共有ボタン → ホーム画面に追加。
- **Android**：Chrome のメニュー → アプリをインストール。

一度開けばオフラインでも読めます。文字認識データ（初回約15MB）と韓国語修正モデル（約28MB）は、最初に本を入れるときに一度だけダウンロードします。

## 自分のリポジトリで使う（フォーク）

1. このリポジトリをフォークするか、ファイルを新しいリポジトリにアップロードします。
2. Settings → Pages → Branch を `main` / `(root)` にして保存します。
3. しばらくすると `https://<アカウント>.github.io/<リポジトリ>/` で開きます。

ビルド作業はありません。HTML と JavaScript のファイルを直せばそのまま反映されます。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の枠と見た目 |
| `src/app.mjs` | 書斎・目次・読書・マーカー・設定の画面 |
| `src/importer.mjs` | 本の追加と章分けの画面 |
| `src/ocr.mjs` | PDF の文字取り出し、文字認識、章節・英語の読み直し、誤字修正 |
| `src/chapters.mjs` | 行の大きさと位置から章タイトル・サブタイトル・聖書の引用・段落を見つける |
| `src/glossary.mjs` | 大事な言葉を守る |
| `src/refs.mjs`、`src/bible-meta.mjs` | 聖書の章節の修正と章・節数の表 |
| `src/ai.mjs` | AI の選択と依頼文 |
| `src/i18n.mjs`, `src/i18n-dict.mjs` | 画面の言語と翻訳辞書 |
| `src/store.mjs` | 端末内の保存（IndexedDB） |
| `src/ko-fix.mjs` | hwp2docx の韓国語誤字修正 |
| `vendor/` | pdf.js、Kiwi 言語モデル |
| `sw.js`, `manifest.webmanifest` | インストールとオフライン利用 |
